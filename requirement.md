Non-functional requirements
How well the application should work.
- Usability: Simple and user-friendly interface.
- Performance: Display tasks quickly.
- Reliability: Store and retrieve task details correctly.
- Security: Protect personal information if user accounts are implemented.
- Compatibility: Work on common web browsers.
- Maintainability: Keep the code organized and easy to update.
Hardware and software requirements
- Hardware: Computer or smartphone, minimum 4 GB RAM recommended.
- Software: Windows/Linux/macOS, modern web browser, code editor.
- Development tools: VS Code, Git, and GitHub.
